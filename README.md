# FormLang DSL Generator

FormLang DSL Generator is a simple tool to create HTML forms using a custom Domain-Specific Language (DSL). It allows you to define forms, sections, fields, and validations in an easy-to-read format, and generates the corresponding HTML output automatically.

## Features
- Define forms with multiple sections
- Add input fields with different types (text, number, email, etc.)
- Add validations like required fields, min/max length, etc.
- Generates clean HTML for your forms

## How to Use
1. Write your form structure using FormLang syntax.
2. Run the DSL generator.
3. Get the generated HTML output for your web page.
